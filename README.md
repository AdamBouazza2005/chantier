# Plans · BOUAZZA IMMO

Application de plans pour le chantier. Rien d’autre :

- En bas, choisissez le niveau : **RDC, 1, 2, 3, 4**.
- Le plan du niveau s’affiche. Zoomez avec deux doigts (ou touchez deux fois), déplacez avec un doigt.
- Touchez un appartement : son plan s’affiche en grand, zoomable aussi.
- Bouton en haut à gauche pour revenir au niveau.

Fonctionne sans réseau après la première ouverture.

## Mise en ligne (GitHub Pages)

1. Nouveau dépôt GitHub, par exemple `plans`.
2. **Add file → Upload files** : envoyez le **contenu** de ce dossier (pas le zip) ; `index.html` doit être à la racine.
3. **Settings → Pages** : *Deploy from a branch*, branche **main**, dossier **/ (root)**, **Save**.
4. Ouvrez l’adresse sur le téléphone, puis **Installer l’application** (Android) ou **Partager → Sur l’écran d’accueil** (iPhone).
